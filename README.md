# todo-ios-site

Static site for **Todo by Bartas** on GitHub Pages: a minimal landing page with privacy policy and support information for the iPhone app by Bartas Urba LLC. No build step—plain HTML and CSS served from the repository root on the `main` branch.

Published URLs: [Privacy Policy](https://barturba.github.io/todo-ios-site/privacy/) and [Support](https://barturba.github.io/todo-ios-site/support/).
